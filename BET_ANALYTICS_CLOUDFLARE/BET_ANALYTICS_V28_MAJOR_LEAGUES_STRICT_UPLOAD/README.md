# BET ANALYTICS V28 — Pronosoft / ligues majeures strictes

V28 conserve Pronosoft comme source publique, mais supprime la règle « toute D1 masculine ».
Une compétition doit désormais être dans une whitelist explicite de championnats majeurs.

Exemples acceptés : Premier League, Ligue 1, LaLiga, Serie A, Bundesliga, Portugal,
Turquie, Pays-Bas, Belgique, Écosse, Suisse, Autriche, Danemark, Norvège, Suède,
Finlande, Pologne, MLS, Brésil, Argentine, Mexique, Japon, Corée du Sud, Chine,
Arabie saoudite, Australie, UEFA Champions/Europa/Conference, Libertadores,
Sudamericana et Leagues Cup.

Exemples rejetés : D1 Algérie, D1 Colombie, autres D1 non whitelistées, féminin,
jeunes, réserves, D2 et coupes domestiques.

L'interface garde le correctif V27 qui sélectionne automatiquement la prochaine date
réellement disponible dans Pronosoft si la date locale ne contient aucun match accepté.
